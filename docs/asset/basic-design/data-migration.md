## 1. 該当なし声明

**本件に移行対象データは存在しない**（新規構築・既存システムなし）。

- RD-02 NFR-12（既存システムからのデータ移行は行わない・移行検証は不要）の正式な引受文書として本書を位置づける。
- デモデータは手動シード（手動投入）であり、移行ツール・移行プログラムは作成しない（RD-07 §3「移行データ：なし」）。

## 2. 雛形 8 項目の該当なし確認

| 項目 | 判定 | 理由 |
|---|---|---|
| 移行対象データ | 該当なし | 新規構築。13 モデル＋P0-2 計画増分はすべて新規作成 |
| 移行元システム | 該当なし | 移行元の既存システムが存在しない |
| 移行方式 | 該当なし | 一括・段階・並行稼働のいずれも対象外 |
| コード変換・クレンジングルール | 該当なし | 移行データがないため。コード値の値域は BD-08 で新規定義 |
| 移行スケジュール | 該当なし | 本番移行日・リハーサルの計画なし |
| 検証方法 | 該当なし（対象外確認のみ） | RD-02 NFR-12 の検証方法＝対象外確認のみ |
| ロールバック手順 | 該当なし | 移行処理が存在しないため |
| 移行対象外データ | 該当なし（対象自体が存在しない） | — |

## 3. 将来検討（本番化時の検討項目リスト）

生産展開（RD-07 §6 前提 6 の再協議）時に既存データが存在する場合は、本書を改版し雛形 4.13 の 8 項目を正式に定義する。先行検討事項：

1. クレンジングの要否（電話番号・メールの形式統一、必須欠損の補完方針＝補既定値の業務確認）。
2. 件数・金額両面の対合（件数照合＋サンプリング人工確認）とリハーサル 2 回以上。
3. ロールバック手順とバックアップ取得（現状はバックアップ運転未整備・BD-10 §6）。
4. コード値（BD-08）と投影レコード（`Booking__c`）の事前整合（移行時に version・syncStatus の初期値方針を決定）。
