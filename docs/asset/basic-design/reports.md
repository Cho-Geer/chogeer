## 1. 該当なし声明

**本件に該当する帳票は存在しない**（帳票 ID：発行なし）。

- 帳票・PDF・CSV／Excel 出力機能は現システム（Booking System／Salesforce 連携スライス）のいずれにも**存在しない**（`booking-backend/docs/api-contract.md` 実測：出力系端点なし。ソースコードにも出力処理なし・2026-08-31 読取）。
- BD-02『機能一覧』の対象外事項にも帳票・出力機能は含まれず、RD-01〜RD-08 の要件・業務（BIZ-01〜BIZ-16）のいずれも帳票を出力契機としない。
- 統計情報（`GET /v1/bookings/stats/summary` 等）は**画面表示のみ**（S-04 統計サマリ）であり、帳票・ファイル出力を伴わない。なお `api-contract.md` 記載の `/v1/system/reports/*` は `SystemModule` 未インポートのため現状不可用である（BD-01 §5 注記・契約文書から復元しない）。

## 2. 将来検討（P1 以降に帳票需要が生じた場合の留意点）

帳票（CSV 出力を含む）を追加する場合は、雛形（交付物雛形集 4.7）の 9 項目を帳票 ID 付きで定義すること。特に外部システム連携で事故が多い次の点を先行確認する。

| 留意点 | 内容（雛形 4.7 の要点引用） |
|---|---|
| CSV 文字コード | Excel で開く前提なら BOM 付き UTF-8 または Shift_JIS の明示。無宣言を禁止 |
| 改行コード | CRLF／LF を I/F・帳票ごとに明記（雛形の「必須記載」項目） |
| 囲み文字・ヘッダ | 囲み文字（二重引用符）の有無・ヘッダ行の有無・日付形式を固定 |
| 金額・桁区切り | 小数位・桁区切りの有無・負数表記を定義 |
| 保存期間・権限 | 出力可能ロール・ファイル保存期間・PII 混入の有無を設計段階で凍結 |
