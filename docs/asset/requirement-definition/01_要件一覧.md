## 1. 文書の目的

本件（Booking System × Salesforce Experience Cloud 連携）の機能要件を、ID・分類・発生源・対応業務・優先度・受け入れ条件・状態付きで一覧化する（非機能要件は RD-02『非機能要件一覧』に分離）。本書が基本設計（機能 F-xx / 画面 S-xx / データモデル）へのトレーサビリティの出発点となる。

- 対象範囲の注記：基本設計機能一覧の F-15（ファイルアップロード）は、本スライス（予約 × EC 連携）の対象外のため要件化対象外とする（RD-03 の業務にも含まれない）。
- 状態の定義：実装済 = Booking System に既存実装あり（2026-08-31 時点・コード読取による裏付け）。検証済 = 実環境での検証完了。部分実施 = スコープの一部のみ実装完了（工程進行中・残スコープを明記）。未着手 = 計画あり・実装なし。保留 = 後続フェーズ（P1）へ持ち越し。却下 = 今回実施しない（対象外）。
- 真実性原則：設計目標・計画を実装済／検証済と記載しない。
