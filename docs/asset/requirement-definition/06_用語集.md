## 1. 文書の目的

両領域（Booking System／Salesforce）の用語を統一し、ERD（docs/asset/basic-design/erd.md）・機能一覧（function-list.md）の物理名と同一の綴りを固定する。**物理名候補は既存資産の命名と一致させており、新規の綴りを製造していない**。🔵 印は P0 計画（未実装）のアセットであることを示す。なお「用語名」列の中国語はテンプレート規定の三言語表記（日本語 / 英語 / 中国語 参考）であり、本文（定義・同義語等）には中国語を使用しない。

## 3. 命名の注記

- 🔵 を付した物理名は P0-2〜P0-4 の計画値であり、erd.md・function-list.md・system-architecture.md の記載と一致させる。本書で新規の綴りを製造していない。
- 静的操作者マッピング（TERM-26）のみ、P0 の実装名が未確定のため「P0-3 で確定（P1 計画名 SalesforceUserLink）」と記載した。P1 の `SalesforceUserLink` は基本設計系資料（P1 展望）に由来する既出の名前である。
- External ID（TERM-14）は 2026-09-01 に uuid `id` と決定済み。本書の物理名候補は決定値に更新済み。
- 「用語名」列の中国語はテンプレート規定の三言語表記であり、中国語残留スキャンの対象外とする（§1 参照）。
